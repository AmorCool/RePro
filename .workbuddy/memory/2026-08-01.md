## test2 通知权限移植（v1.1.57）— 已完成代码并核对

从 test2 源码（ReProvision-Reborn）移植通知能力，核心目的：RootHide 下通知授权持久化。

- 新增 `App/Sources/Notifications/`：`HookUtil.h`/`HookUtil.c`（自带 fishhook 重写，零依赖）、`RPVNotificationManager.h`/`.m`。
- 核心 Hook：`HOOK_MESSAGE(UNUserNotificationCenter, initWithBundleIdentifier_, ...)` 强制把 bundle id 回落到 `[[NSBundle mainBundle] bundleIdentifier]`，避免 RootHide namespace 隔离把授权落进 jbroot overlay 的 TCC（导致杀后台后失效、反复弹窗）。`__attribute__((constructor))` 自动安装。
- 去依赖：去掉原版 RMessage / RPVLocalization / RPVResources；开关改读 NSUserDefaults（`notificationsEnabled` 默认开、`notificationsDebug` 默认关）；最低 iOS 15，去 UILocalNotification 分支。
- 桥接：`RePro-Bridging-Header.h` 增 `#import "RPVNotificationManager.h"`；`sendNotification(title:body:isDebug:identifier:)` / `fetchAuthorizationStatus(completion:)` 已对 Swift 暴露。
- 发送逻辑集中在 `BridgeClient.swift`：`installSigningNotificationHooks()` 统一接管 `bridge.signingProgressHandler/errorHandler`，转发给通知 + 外部 handler，避免与 SigningViewModel 抢全局 handler。进度 10/50/60/90→「调试」(isDebug)，100→「重签完成」，错误→「签名失败」，流水线结束 101(no signing required)→「无需重签」、其他→「重签失败」。
- `AppDelegate.swift`：非静默分支 `registerToSendNotifications()`；静默续签 `exit(0)` 前 `Thread.sleep(0.8)` 留通知 XPC 提交窗口。
- `SettingsView.swift`：新增「重签通知」「详细通知」开关 + 系统授权状态 + 前往设置（`UIApplication.openSettingsURLString`）。
- `gen_pbxproj.py`：`App/Sources/Notifications` 入 `VENDOR_HEADER_DIRS`；`HookUtil.c`+`RPVNotificationManager.m` 入 `bridge_src`/头；`UserNotifications.framework` 入 `SDK_FRAMEWORKS`；`MARKETING_VERSION = "1.1.57"`。已重生成 `project.pbxproj`（Swift 14，被编译 99 文件，含新源 + framework）。
- `Packages/*/DEBIAN/control` 版本统一 `1.1.57~release`。`MainView.swift`/`repro-signingd.m` 仍含上一轮撤销快捷指令的改动。
